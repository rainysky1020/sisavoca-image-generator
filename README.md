# 시사보카 연상 삽화 제작기

캐릭터 형태는 [다람쥐 캐릭터 시트3](./다람쥐%20캐릭터%20시트3.jpg)을 기준으로 합니다. [샘플1](./샘플1.jpg)·[샘플2](./샘플2.jpg)·[샘플3](./샘플3.jpg)은 선명한 소품 색상과 따뜻하고 활기찬 분위기의 참고 이미지로 생성·검토·수정에 사용합니다. 주 요소를 균형 있게 크게 강조하고, 떨어뜨리는 장면은 떨어지는 사물을 중심에 둡니다. 비교가 뜻 전달에 도움이 되면 비교 구성을 사용하며, 한국어 뜻이 적힌 말풍선은 금지합니다.

단어 CSV를 읽어 학습에 유익한 삽화만 제작하는 로컬 웹 프로그램입니다. `gpt-6-sol`이 제작 전에 장면과 뜻을 바로 보여줄 동작·표정·표시를 설계하고 그릴 수 없는 뜻은 생략합니다. `gpt-image-2`의 `quality=low`가 [다람쥐 캐릭터 시트3](./다람쥐%20캐릭터%20시트3.jpg)를 참고해 삽화를 만듭니다. 현재 계정에서는 800×800 직접 생성이 거절되어, 1024×1024로 생성한 뒤 **순백색(`#FFFFFF`) 불투명 배경의 800×800 PNG**로 납품합니다. 새 삽화는 [화풍 기준](./STYLE_REFERENCE.md)을 다람쥐 등장 여부와 관계없이 적용합니다. 생성된 그림은 검토 후 그대로 납품하거나 한 번 수정합니다. 수정했다면 원본과 수정본을 비교해 더 나은 한 장을 선택하며 자동 폐기하지 않습니다.

## 실행

Python 3.11 이상과 Pillow가 필요합니다.

Windows에서는 [start.bat](./start.bat)을 더블클릭하면 됩니다. Pillow가 설치되지 않았다면 자동으로 설치하고, 로컬 서버가 시작되면 브라우저를 엽니다. 검은 실행 창을 닫으면 서버도 종료됩니다.

```powershell
python -m pip install -r requirements.txt
python app.py
```

브라우저에서 `http://127.0.0.1:8765`를 엽니다. `.env`에 `OPENAI_API_KEY=...`가 있어야 합니다. 운영체제 환경 변수로 제공해도 됩니다. 키는 로컬 서버에서만 읽습니다. 포트를 바꾸려면 `SISAVOCA_PORT` 환경 변수를 설정합니다.

## 입력 CSV

UTF-8 또는 UTF-8 BOM CSV를 사용합니다. [sample_vocabulary.csv](./sample_vocabulary.csv)를 복사해 시작할 수 있습니다.

| 열 | 필수 | 내용 |
| --- | --- | --- |
| `word` | 예 | 표제어 |
| `meaning_ko` | 예 | 삽화가 표현해야 할 한국어 뜻 |

파일은 최대 5MB, 1,000행입니다. 필수 값 누락·행 형식 오류는 해당 행을 `error`로 기록합니다. 언어는 원어 단어를 바탕으로 모델이 판단합니다. 같은 표제어가 여러 행에 있어도 각각 처리합니다. 작업을 시작한 뒤에는 현재 처리 중인 API 요청이 끝난 다음 중단됩니다. 재개 시 완료된 행은 다시 생성하지 않습니다. 처리 도중 끊긴 행은 처음부터 다시 처리할 수 있어 그 행의 API 호출이 중복될 수 있습니다.

## 결과

각 작업 결과는 `output/<작업 ID>/`에 저장됩니다. PNG 파일명은 원어 단어를 최대한 그대로 사용합니다(예: `umbrella.png`, `驚く.png`). 같은 이름이 다시 나오면 `umbrella (2).png`처럼 번호를 붙이며, 파일명에 사용할 수 없는 문자만 `_`로 바꿉니다. 프로그램은 납품 전에 PNG가 800×800 RGB이며 빈 바깥 배경이 정확한 `#FFFFFF`인지 확인합니다. 웹 화면에서 납품 PNG를 개별 또는 ZIP 묶음으로 받고, `work_report.xlsx`를 내려받을 수 있습니다. 보고서의 `요약` 시트는 건수·모델 설정·성공한 API 호출 수·반환된 토큰 사용량을 담고, `단어별 상세` 시트는 모든 입력 행의 판단·검토·수정·납품 결과를 담습니다. 금액은 API 응답만으로 정확한 과금이 확인되지 않아 계산하지 않습니다.

자동 검토는 의미 전달과 기억 단서를 우선합니다. 화풍의 경미한 차이는 보고서에 참고 사항으로 남기고 납품할 수 있습니다. 다람쥐 손·발의 손가락·발가락·분리선뿐 아니라 팔의 결손·중복·돌출, 입의 결손·중복·이탈, 공포감을 주는 과장된 눈도 확인합니다. 캐릭터 핵심 형태 변경, 다른 얼굴 있는 캐릭터, 넓은 명암·입체감, 복고풍 또는 과한 장식, 뜻 전달 단서 부족도 수정 대상으로 봅니다. 수정 후에는 원본과 수정본의 뜻 전달·기억 효과를 먼저 비교하고 더 나은 쪽을 납품합니다. 어느 쪽에도 문제가 남으면 보고서에 적어 편집자가 최종 확인할 수 있게 합니다. 검토나 수정 API 호출에 오류가 나면 이미 생성한 원본을 납품하며, 생성 자체가 실패하거나 유효한 PNG로 만들 수 없으면 오류로 기록합니다. **기존 납품 이미지와 이미 폐기된 작업은 변경하지 않습니다.** 프로그램 재시작 뒤 새 작업에 적용됩니다.

가리키는 뜻이나 장면에서는 손·검지로 가리키지 않고 시선·몸 방향·별도 화살표·대상 위치로 표시합니다. 팔 끝이 검지처럼 가늘거나 길게 뻗어도 자동 검토에서 수정 대상으로 다룹니다. 원본과 수정본 중 한쪽만 손가락 없이 뜻을 전달하면 그쪽을 선택하도록 합니다.

같은 사물이 다시 등장하면 이전에 납품한 그림의 해당 사물을 이미지 참고 자료로 함께 보내 형태·색·윤곽선·특징을 맞춥니다. 사물 이름은 설계 모델이 한국어 기본형으로 기록하고, 프로그램은 완료된 작업의 기록에서 같은 이름을 찾아 가장 먼저 납품한 그림을 기준으로 사용합니다. 그림 전체 장면은 복사하지 않습니다. 한 번에 최대 두 개의 사물 참고 이미지를 사용합니다. 사물 재사용 여부와 참고 파일은 엑셀 보고서에 남습니다. 이 기능은 새 버전에서 사물 이름을 기록한 작업부터 적용되며, 이전 버전의 기존 PNG를 자동으로 분석하거나 다시 그리지는 않습니다.

## GitHub로 공유

현재 GitHub 저장소는 공개 상태입니다. `.env`, `voca*.csv`, `voca*.xlsx`, `output/`은 Git에서 제외됩니다. 코드를 받은 사람은 `.env.example`을 `.env`로 복사하고 **자신의** API 키를 입력해야 합니다. 캐릭터 시트와 문서도 공개 저장소에 포함되므로 배포 권한을 확인하세요.

공개 저장소를 받은 사람은 GitHub의 **Code → Download ZIP**을 사용하거나 다음처럼 복제할 수 있습니다.

```powershell
git clone https://github.com/rainysky1020/sisavoca-image-generator.git
cd sisavoca-image-generator
python -m pip install -r requirements.txt
Copy-Item .env.example .env
# .env 파일에 자신의 OPENAI_API_KEY를 입력한 다음
python app.py
```

브라우저에서 `http://127.0.0.1:8765`를 열면 됩니다. 공개 저장소는 누구나 내려받을 수 있지만 GitHub에 변경 사항을 올릴 권한은 저장소 소유자나 승인된 협업자에게만 있습니다.
